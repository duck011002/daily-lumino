# 关键里程碑

里程碑文档记录一次跨功能发布或基础设施切换，不替代功能目录中的 `current.md`、`implement.md` 和 `walkthrough.md`。

每个里程碑至少记录：

- 目标与范围
- 起始 commit 与结束 commit
- 实施文档链接
- 实际执行命令
- 本地测试结果
- 生产部署结果
- 线上冒烟结果
- 未完成事项与回滚点
